# MediKiosk Connect

Build a modern, innovative responsive web app called **MediKiosk – AI-Powered Clinical History & Patient Intake**.

Main flow:
**Patient Login → Language Selection → Consent → AI Voice/Touch Interview → Adaptive Questions → Red-Flag Detection → Upload/Scan Medical Documents → OCR & Data Extraction → Medical Timeline → AI Clinical Summary → Physician Review → HIS/ABHA Mock Integration.**

Key features:

- Multilingual voice + text/touch interaction, especially Indian languages.
- Simple UI for elderly and low-literacy users.
- AI adaptive questioning for chief complaint, HPI, past history, medicines, allergies, family/personal history and review of systems.
- AYUSH mode with **Dashavidha Pariksha**.
- Red-flag/emergency symptom alerts for staff.
- Upload prescriptions, lab reports and discharge summaries.
- OCR extracts medicines, diagnoses, investigations, values and dates.
- Highlight abnormal lab values.
- Organize records into a chronological medical timeline.
- Generate an editable **physician-ready clinical summary** with source-document traceability.
- Physician, triage-staff and patient dashboards.
- Consent, privacy, role-based access and automatic kiosk session reset.
- Use clearly marked **DEMO DATA** and mock AI/API integrations where real services are unavailable.
- Never diagnose or prescribe; AI output must say **“AI-generated draft — physician verification required.”**

Design it with a clean futuristic healthcare UI, large touch-friendly buttons, voice waveform, AI assistant, smooth animations and a professional **green/teal + white** medical theme.Make the complete flow **fully clickable and demo-ready**, not just static screens.
